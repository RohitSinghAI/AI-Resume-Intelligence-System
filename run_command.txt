Backend command:
uvicorn app.main:app --reload

Frontend command:
npm run dev

Virtual environment activate:
.\venv\Scripts\Activate.ps1

Install requirements:
pip install -r requirements.txt

Docker command:
docker run -d --env-file .env -p 8000:10000 --name resume-backend-container --restart unless-stopped ai-resume-backend:latest
docker start resume-backend-container

Docker stop command:
docker rm -f resume-backend-container
